# 决策反馈循环

AI 决策建议的行为规范 Skill——让 Agent 输出决策建议时自带防跑偏检查、互动反馈卡片和台账写入闭环（Decision Feedback Loop）

## 项目解决什么问题

Agent 给出选品推荐、质量评估、数据分析结论后，不知道人是否采纳、为什么不采纳，错误无法沉淀。源自 Weee! 采购部门"否决必须留理由"机制：AI 给建议 → 人采纳/不采纳 → 反馈写台账 → AI 变聪明。

## 主要功能

| 能力 | 说明 |
|------|------|
| 规则 1：关键数字回源核实 | 最高优先级——涉及价格、库存、销量等关键数字必须先核实来源 |
| 规则 2：附带反馈卡片 | 决策建议自动附带飞书互动卡片（采纳/部分采纳/不采纳 + 原因），两次推送模式（V4） |
| 台账写入闭环 | 首次使用自动创建专属「AI 决策反馈台账」多维表格，记录反馈原因 |
| 不压缩原则 | 本技能是附加行为规范，不得压缩 AI 本来要回答的内容 |
| 边界明确 | 卡片回调处理、AI 不允许"代填"用户反馈、发卡后继续对话 |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 需要飞书互动卡片与多维表格能力（回调处理、台账创建）

## 使用方法

适用于所有 A 类（决策建议型）Agent：输出可采纳/可否决的决策建议、涉及价格库存销量等关键数字时自动触发。

## 输入输出示例

**输入：** 给出这 3 个款式的选品推荐
**输出：** 选品建议（关键数字已回源核实）+ 飞书反馈卡片 + 台账记录入口
